# AI InterviewIQ - Smart Interview Practice Platform

A full-stack AI-powered interview practice application built with React, Node.js, Express, MongoDB, and OpenAI integration.

## 🚀 Features

### Core Functionality

- **AI-Generated Questions**: Dynamic interview questions generated by OpenAI GPT
- **Real-time Feedback**: Instant AI-powered scoring and feedback on answers
- **Voice Recording**: Record and playback voice responses during interviews
- **Credit System**: Purchase interview credits to access the platform
- **User Authentication**: Secure Google OAuth login
- **Interview History**: Track and review past interview performances
- **Analytics Dashboard**: Comprehensive performance statistics and trends

### User Experience

- **Responsive Design**: Mobile-first design with Tailwind CSS
- **Intuitive UI**: Clean, modern interface with smooth animations
- **Real-time Updates**: Live feedback and progress tracking
- **Secure Authentication**: JWT-based session management

## 🛠️ Tech Stack

### Frontend

- **React 19** - Modern React with hooks and functional components
- **Vite** - Fast build tool and development server
- **Redux Toolkit** - State management
- **React Router** - Client-side routing
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **React Icons** - Icon library
- **Axios** - HTTP client
- **Firebase** - Authentication

### Backend

- **Node.js** - JavaScript runtime
- **Express.js** - Web framework
- **MongoDB** - NoSQL database
- **Mongoose** - ODM for MongoDB
- **JWT** - JSON Web Tokens for authentication
- **OpenAI API** - AI-powered question generation and feedback
- **bcrypt** - Password hashing
- **CORS** - Cross-origin resource sharing

## 🔧 Installation & Setup

### Prerequisites

- Node.js (v16 or higher)
- MongoDB (local or Atlas)
- OpenAI API key
- Firebase project

### Backend Setup

1. Navigate to server directory:

   ```bash
   cd server
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create `.env` file:

   ```env
   PORT=8000
   MONGODB_URL=mongodb://localhost:27017/interviewiq
   JWT_SECRET=your_jwt_secret_here
   OPENAI_API_KEY=your_openai_api_key_here
   ```

4. Start the server:
   ```bash
   npm run dev
   ```

### Frontend Setup

1. Navigate to client directory:

   ```bash
   cd client
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 🔑 API Endpoints

### Authentication

- `POST /api/auth/google` - Google OAuth login

### User Management

- `GET /api/user/current-user` - Get current user info
- `POST /api/user/add-credits` - Add credits to user account

### Interview System

- `POST /api/interview/start` - Start new interview session
- `POST /api/interview/submit-answer` - Submit answer and get feedback
- `POST /api/interview/complete` - Complete interview session
- `GET /api/interview/user/:userId` - Get user's interview history

## 🎯 Usage

1. **Sign Up/Login**: Use Google OAuth to create an account
2. **Dashboard**: View your interview statistics and performance
3. **Start Interview**: Begin a new AI-powered interview session
4. **Answer Questions**: Type or record your responses
5. **Get Feedback**: Receive instant AI scoring and feedback
6. **Review History**: Analyze past interviews and track improvement
7. **Buy Credits**: Purchase more interview credits when needed
